## ⚡ About Me

I am a software engineer and AI researcher passionate about **Autonomous Agent Harnesses**, **Local-First Architectures**, and **Deterministic System Engineering**. I build bridges between next-gen frontier LLMs (Mistral, Claude, GPT, Gemini) and local open-weights intelligence (Ollama, DeepSeek, Qwen).

* 🧠 **Currently architecting:** [HarnessForge](https://github.com/pspelsberg/harnessforge) — Visual state-graph & loop engineering for autonomous AI agents.
* 🛡️ **Core Philosophy:** *Zero cloud lock-in, deterministic execution boundaries, Local Trust Mode, and prompt-as-a-variable workflows.*
* 🔭 **Research Interests:** Recursive Language Models (RLM), ARC AGI challenges, MCP (Model Context Protocol), LanceDB vector search, and hybrid model orchestration.
* 🎨 **Creative Tech:** ComfyUI generative pipelines, procedural game development (Unity), and custom AI tooling.
